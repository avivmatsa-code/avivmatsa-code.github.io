# סיכוי, סיכון ותוחלת

אפליקציית ווב לימודית בעברית ללימוד הסתברות, תוחלת, סיכון, תנודתיות, משחק יחיד מול משחק חוזר, והבדל בין משחק הוגן לבין משחק שבו למפעיל יש יתרון מתמטי.

האפליקציה היא הדמיה לימודית בלבד. אין שימוש בכסף אמיתי, אין הרשמה, אין שרת ואין קישורי הימורים.

## הפעלה מקומית

מומלץ להריץ שרת סטטי מקומי מתוך תיקיית הפרויקט, כדי שמודולי JavaScript ייטענו באופן זהה לפרסום ב-GitHub Pages:

```bash
python -m http.server 8765
```

ואז לפתוח:

```text
http://127.0.0.1:8765/
```

לבדיקות החישוב, אם Node.js מותקן:

```bash
npm test
```

אפשר גם להריץ בדפדפן:

```js
runEducationalAppTests()
```

## פרסום ב-GitHub Pages

1. העלו את כל תיקיית הפרויקט לריפוזיטורי.
2. הגדירו ב-GitHub Pages פרסום מתוך הענף הרצוי ומתיקיית השורש או `docs`, לפי מבנה הריפוזיטורי.
3. אין צורך בבנייה, שרת או משתני סביבה.

## מבנה הקוד

- `index.html` - מבנה המסכים, הטפסים והקנבסים.
- `styles.css` - עיצוב RTL רספונסיבי ונגיש.
- `src/random.js` - מחולל אקראיות, כולל seed קבוע לשחזור בדיקות.
- `src/math.js` - תוחלת, שונות, סטיית תקן, דגימת נקודות ופורמטים.
- `src/simulation.js` - מנועי סימולציה למטבע ולרולטה.
- `src/charts.js` - גרפי קו והיסטוגרמה על Canvas.
- `src/state.js` - שמירת התקדמות מקומית ב-LocalStorage.
- `src/content.js` - שאלות, הסברים ושאלון.
- `src/app.js` - חיבור הממשק למנועי החישוב.
- `tests.js` - בדיקות חישוב ושחזור.

## הנחות חישוב

- מטבע הוגן בסיסי: 50% לזכות ב-10 ש"ח נטו, 50% להפסיד 10 ש"ח נטו.
- תוחלת כללית: `EV = Σ [P(i) × payoff(i)]`, כאשר `payoff` הוא רווח או הפסד נטו.
- רולטה אירופית: 37 תאים, 18 אדומים, 18 שחורים, 0 ירוק.
- אדום/שחור: תשלום נטו פי 1 מסכום ההימור.
- מספר יחיד: תשלום נטו פי 35.
- תריסר: תשלום נטו פי 2.
- תוחלת הימורי רולטה רגילים היא `-1/37` מסכום ההימור.

## הוספת משחקי הסתברות נוספים

1. הוסיפו פונקציית תוחלת ב-`src/simulation.js` או השתמשו ב-`expectedValue` מתוך `src/math.js`.
2. הוסיפו פונקציית סימולציה שמחזירה נתוני סיכום ונקודות לגרפים.
3. הוסיפו מסך או פאנל ב-`index.html`.
4. חברו אירועים וציור גרפים ב-`src/app.js`.
5. הוסיפו בדיקה מתמטית ב-`tests.js`.
